# SlopGuard development

- Write application code, tests and repository automation in C#.
- Use the [SlopGuard skill](skills/slopguard/SKILL.md) for this checkout. On Windows, use the verified build under `%LOCALAPPDATA%/SlopGuard/releases/0.1.0` when available. Start it before C# work and review fresh findings before reporting completion.
- Run `dotnet test SlopGuard.slnx` to verify runtime changes. The current SlopGuard release checks syntax, so build and test results remain necessary for semantic and behavioral verification.
