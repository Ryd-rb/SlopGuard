# Blinded Luna effort comparison

The product basis is current main at `db122b2`. There are three fixed projects and three pairs. Before launching a review, randomly assign one Luna 6 effort level to each project from Low, Medium and High, then randomize the launch order within each pair. Both workers on a project use that project's assigned effort. This measures the assisted difference within each project and effort. Project and effort vary together, which limits comparisons across effort levels.

The projects come from two separate `gpt-6.1-sol` design contexts. One proposed the Kestrel and Wren evidence failures. The other proposed Oriole. The coordinator implemented the projects and independently ran the oracles. Keep the discussions and this file outside the snapshots.

It must hold the proposed handoff, clear the standing handoff and preserve smoke. Verify the applicable SlopHawk component and real TRX case identities where relevant. Reproduce each per-entry content and metadata manifest from a new process, then repeat both dossier and inspector fingerprints after the trial.

## Worker brief and tools

Start each `gpt-6-luna` worker with no forked turns and the same release-review brief, bounded to its own snapshot. Ask for concrete release blockers with raw evidence and a reproduction or minimal correction. Include the standing handoff for false-positive measurement. Both arms have read-only local access and ordinary PowerShell and .NET tools. New output goes to a unique external scratch directory. Exclude networks, other reviews, author work and agents. Cap elapsed review time at four minutes by instruction. Tool-call counts are uncapped in both arms and are measured as used.

Only the assisted brief includes the benchmark inspector and the command `Inspector ROOT archive release/candidate.json`. It emits typed verification observations from production coverage import, TRX replay, receipt validation and build identity comparison. The wrapper joins the selected Oriole receipt stamp to the measured effective profile. The inspector does not resolve Wren's required case set or locate the pair of colliding Kestrel counters. Both arms have all original evidence and can reach the conclusion independently. Neither sees the oracle or peer output. The coordinator scores against the frozen rubric with access to the arm metadata.

Pull input, cached input, uncached input, output, reasoning within output and total logical tokens from the final run-local cumulative runtime event. Include failed commands. Record calls and elapsed time separately. Do not interpret the pooled results as a significance test or differences across effort levels as the effect of effort.
