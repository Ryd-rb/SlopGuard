# Integrated behavioral review iteration

The initial [unassisted protocol](wide-low.md) qualified 100 distinct defects. The first round verified 63 and missed 37. This development iteration keeps all 100 and adds six new handoff faults. Combine related workflows into three independently sealed release dossiers. FieldService combines appointment, maintenance, and dispatch workflows. DataPlatform combines replication, editing, and ingestion. ReportingHub combines billing, catalog, and publication. These larger reviews test discovery and verification under broader scope. The recurring 100 roots mean the second round is a harder packaging and workflow iteration on the original corpus.

An admitted operation uses the producer and current schema revision defined by the routing catalog and requires an accepted proof. Stale or unaccepted executions return the defined out-of-scope value. Source, contracts, manifest and public profiles ship together. The harness runs both accepted and rejected ordinary paths, then verifies every private accepted route with its shipping and repaired implementation. The six new cases exercise same-depot transfers, deferred publication after lease cutoff, competing snapshot deltas, unordered acknowledgment spans, overlap in success rollups and partial tax reversal.

Use one fresh unassisted Luna 6 Low worker per dossier. Retain uncapped calls and allow twenty-four minutes for a 32-defect dossier and thirty-two for the 42-defect dossier. No reviewer receives a seed count or expected result. The verification rule remains a valid counterexample with true output and cause. A business argument vector without its three-field envelope is bound to the single publicly documented admitted route, so this iteration does not count envelope formatting as a miss. Wrong or explicitly inapplicable envelope fields remain part of the replay. Preserve false positives and distinguish localization from exact verification as in the first round. The difficulty criterion is at least 53 misses out of 106 distinct defects in a complete round. Report raw tokens, calls, and elapsed time. Preserve both rounds.

Run `Qualification wide-integrated NEW_ABSOLUTE_DIRECTORY` to build and qualify the three dossiers. Replay submissions with `Qualification adjudicate-integrated ABSOLUTE_CORPUS ABSOLUTE_ANSWERS NEW_ABSOLUTE_OUTPUT`. The layout uses the same private author directory and per-entry manifest process as the first round.
